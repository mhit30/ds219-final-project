
## Will and Will Not Do

The MVP will do:
    1. Allow users to upload a CSV file of their expenses, or add single expenses by hand, and view their data in the app. 
    2. Allows users to setup groupings and budgets of how much they'd like to spend each month on some category. 
    3. Allows users to view graphs and charts of their spending for more insightful GUIs.

The MVP will not:
    1. Connect with Plaid or any other services to integrate all financial data automatically.
    2. Have an AI assistant that can give generative text about financial spending.
    3. Save or upload financial data to the cloud to be portable across multiple devices.
    4. Be on a hosted website.

## How a user runs it

The user will run the application by first cloning it from GitHub to their local machine, cd'ing into the directory, and running npm run start. Here are the exact commands:

```
git clone git@github.com:mhit30/ds219-final-project.git

cd ds219-final-project

npm install 

npm run start
```
## Language and Framework

The application will primarily be written in JavaScript with the React.js library. Furthermore, we will also be using HTML and CSS to develop the graphical user interface. Furthermore, we will be using the NPM package management tool.
